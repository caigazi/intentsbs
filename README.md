# IntentComm-SBS

Clean development snapshot for distributed two-dimensional Intent coordination
of multi-robot A-SBS, with an independent analytic Wang safety backend.

Start with [START_HERE.md](START_HERE.md). A new Codex task opened in this
directory should follow [AGENTS.md](AGENTS.md) automatically.

This folder intentionally excludes legacy experiment videos, obsolete datasets,
old conversation transcripts, 0.21 s/100 Hz branches and historical result
directories. Those remain in the old workspace only as diagnostic history.
